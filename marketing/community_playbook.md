# 커뮤니티 침투 준비 — 실사 결과 + 실행 자료

작성: 2026-08-07. GROWTH.md §Week1-4 "C. 커뮤니티 침투"의 실행 준비물.

**이 문서가 못 하는 것**: 계정 로그인·댓글 작성·카페 가입은 내가 대신 할 수 없다
(로그인/계정 관련 행동은 항상 사람이 직접). 아래는 그 직전까지 — 어디에, 뭐라고
쓸지 — 다 준비해둔 것이다.

---

## 0. 원칙 (어기면 역효과)

- **홍보글 금지.** 새 글을 안 쓴다. 이미 있는 질문·글에 우리 데이터로 답만 한다.
- **첫 댓글에 링크부터 걸지 않는다.** 특히 카페는 "정보 공유 위장 홍보"에 민감하다 —
  실사 중 실제로 "카페 운영진이 경쟁 정보로 인식하면 강제 퇴출한다"는 후기를
  발견했다(아래 §2 카페 항목). 처음 몇 번은 링크 없이 순수하게 답만 하고,
  계정에 활동 이력이 쌓인 뒤에 링크를 곁들인다.
- **링크는 항상 UTM을 붙인다** — 안 붙이면 어느 채널이 먹히는지 못 잰다(GROWTH.md §3.5).
- **커뮤니티마다 규칙이 다르다.** 가입 전에 그 커뮤니티의 홍보 관련 규정을 먼저 읽는다.

## 1. 채널별 실사 결과

### ✅ 월부(weolbu.com) N잡아카데미 숙박업 — 1순위, 지금 바로 가능

- **실사 확인**: 로그인 없이 전체 칼럼 + 댓글 열람 가능. 크리에이터 "반반꿈"
  (에어비앤비로 시작해 모텔 사장이 된 직장인)이 연재 중, 현재 12화+.
  댓글도 공개 노출되고 실제 질문성 댓글이 달린다(예: EP12에 "법이 실제로
  실현되는지 확인해야겠다"는 독자 반응).
- **댓글 작성엔 로그인 필요**(카카오 3초 가입 유도 문구 확인).
- **왜 1순위인가**: EP12("내국인도 공유숙박 허용?! 2026년 에어비앤비 전망과 생존
  전략", 2026-01-18)가 **서울/부산 vs 지방의 유불리를 정확히 우리 이달의 발견과
  같은 주제로 다룬다.** 반반꿈은 감(정성적 전망)으로 "서울/부산 흐림, 지방 맑음"을
  얘기했는데, 우리는 **실측 등록 데이터로 정반대 방향(서울·부산만 성장, 지방은
  등록이 줄어드는 중)** 을 갖고 있다 — 콘텐츠에 반박이 아니라 "실측 데이터를
  더하는" 형태로 붙일 수 있는 보기 드문 기회다.
- **URL**: https://weolbu.com/community/3760113
- 실행: §3 참고.

### ⚠️ 네이버 카페(에어비앤비 호스트 카페들) — 유효하지만 위험 신호 있음

- 실사 중 두 개의 독립적인 경고를 발견했다:
  1. "카페 운영진이 자기 이익 추구에 집중하고, 경쟁이 될 만한 정보 공유 글은
     쫓아낸다"는 실사용자 후기(finestays.com 호스트 커뮤니티).
  2. 아이보스에도 "카페 최적화 아이디", "카페 저품질" 등 카페 운영진 스스로가
     SEO·홍보 목적으로 카페를 사고파는 경우가 흔하다는 정황 다수.
- **결론**: 카페가 무조건 나쁜 채널은 아니지만, **처음부터 링크를 걸면 운영진이
  "경쟁 정보"로 인식해 삭제·차단할 위험이 실제로 있다.** §0 원칙(링크 없이 먼저
  활동 이력 쌓기)이 특히 여기서 중요.
- 구체적 카페 URL은 못 얻었다 — 가입 승인이 필요한 폐쇄형이 많아 로그인 없이는
  카페명·회원수·게시판 구조를 확인할 수 없었다. **사용자가 직접 "에어비앤비 호스트",
  "공유숙박 호스트" 등으로 네이버 카페 검색 → 가입 전 카페 소개·최근 게시글
  활동성부터 눈으로 확인**하는 걸 권장(가입 인원보다 최근 게시글 빈도가 진짜 활성
  지표다 — 위 후기가 지적한 "회원수와 실제 이용자 수 불일치" 문제).

### ❌ 아이보스 — 제외 권장 (GROWTH.md 원래 계획 수정)

- 실사 결과: 34만 명 규모는 맞지만, **커뮤니티 내용이 전부 "마케팅 기법"
  (카페 최적화, 네이버 키워드 광고, SEO)** 이다. 숙박업·부업·에어비앤비 얘기가
  아니라 **"마케터들이 마케팅 얘기하는 곳"** — 이 리포트를 프로스펙티브 호스트에게
  전달하려는 목적과 맞지 않는다.
- GROWTH.md에는 "규모"만 보고 넣었던 항목이라 여기서 정정한다. **커뮤니티
  침투 대상에서 빼고, 대신 아래 §Threads를 그 자리에 넣는다.**

### 🆕 Threads(스레드) — 추가 권장

- 실사 중 실제 개인 에어비앤비 호스트 계정(예: `@suit_tt_` "에어비앤비 호스트의
  일상")이 활동 중인 걸 확인 — 이 주제의 개인 사용자가 실제로 있는 플랫폼이다.
- "커뮤니티"라기보다 **알고리즘 피드**라 가입·승인 개념이 없고, 카페처럼 운영진에게
  차단당할 리스크가 없다 — 우리 계정으로 직접 짧은 글을 올리면 된다(별도 조사
  자료: 골든타임 출근시간대 8-9시·밤 11시-새벽1시, 댓글 유도가 도달을 결정).
- 회사 SNS 계정 여부는 이전 대화에서 "없음"으로 확인됐다 — 이 채널을 쓰려면
  **계정을 새로 만들어야 한다**(계정 생성은 사용자가 직접).

### 🔍 확인 필요 — 베스트앤잡(best-and.com)

- N잡 커뮤니티, 수익인증 스타일 게시글이 있다는 것까지만 확인. 게시판이 로그인
  없이 보이는지, 숙박업 관련 스레드가 실제로 있는지는 못 봤다 — 시간 나면
  직접 확인 후 §1 목록에 추가할지 결정.

## 3. 재사용 답변 템플릿 (질문 유형별)

실제 커뮤니티에 아래와 똑같은 질문이 보이면 이 템플릿을 자기 말투로 다듬어 쓴다.
전부 **답 + 근거 링크** 구조 — 절대 "위홈 마켓리포트 확인해보세요"로 끝내지 않는다.

### A. "어느 지역이 괜찮을까요?"
> 지역마다 등록 밀도·최근 증감이 꽤 달라요. 저는 행안부 원본 등록 데이터를
> 직접 집계한 사이트에서 확인하는 편인데[링크], oo구 기준으로는 [실제 숫자
> 언급] 상태더라고요. 규모만 크다고 좋은 게 아니라 최근 신규 유입이 꺾이는
> 구는 오히려 포화 신호일 수 있어서 그것까지 같이 보는 걸 추천드려요.

링크: `https://wehome-market-report.vercel.app/estimate.html?utm_source=community&utm_medium=community&utm_campaign=host_qna&utm_content=region_question`

### B. "지금 시작해도 포화 아닌가요?"
> 전국 단위로 보면 아직 포화라기보단 지역별 편차가 커요. [해당 지역] 기준으로는
> 최근 6개월 신규등록이 [증가/감소]하는 추세더라고요. 여기[링크]서 지역
> 하나 골라서 보면 등록 추이·진입 적합도 지수까지 나와요.

링크: 질문자가 특정 지역을 언급했으면 해당 `area/{시도}-{시군구}.html` 페이지로
직접 연결(전국 68개 지역 페이지 있음 — 없는 지역이면 estimate.html로).
예: `https://wehome-market-report.vercel.app/area/서울특별시-마포구.html?utm_source=community&utm_medium=community&utm_campaign=host_qna&utm_content=saturation_question`

### C. "이 동네 등록 몇 곳이나 있어요?"
> [동네] 기준 영업중 [N]곳이고 전국 [순위]위더라고요. 상세 데이터는 여기[링크].

링크: 해당 area 페이지 (있으면), UTM `utm_content=count_question`

### D. 규제·법안 관련 질문 ("실증특례가 뭐예요", "내국인 허용되나요" 등)
> 저희도 헷갈려서 국회 계류법안이랑 문체부 발표를 자동으로 모아보는 대시보드를
> 참고해요[링크] — 관광진흥법 개정 관련 건만 따로 추적돼서 편해요.

링크: `https://wehome-market-report.vercel.app/dashboard.html?utm_source=community&utm_medium=community&utm_campaign=host_qna&utm_content=regulation_question`

## 5. 하지 말아야 할 것 (재확인)

- [ ] 새 글(스레드) 만들어서 링크부터 걸기 — 하지 않는다
